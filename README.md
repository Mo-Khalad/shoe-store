<h1> SHOE STORE</h1>
<p>An attractive and modern design that adapts to all screen sizes, featuring a navigation bar
  , homepage, products section, "About Us" section (which is a slider made using only JavaScript for the site)
  , customer reviews section (which is a accordion made using only JavaScript)
  , services section, footer section, and login section.</p>

  <h3>Tools</h3>
  <p>html , css , bootstrap , js </p>

  <h3>features</h3>
  <ul>
    <li>Attractive design that is responsive across all screen sizes.</li>
    <li>Navigation bar between site sections for more information.</li>
    <li>The slider was designed using only JavaScript, and features automatic and manual display.</li>
    <li>Accordion is built using only JS without any supporting libraries.</li>
  </ul>
